# Milo v0.5.0（预发布）

## 本次重点

首页和分页采用全宽标题，窄平板留出更多空间阅读文章。

## 新增

本次无新增功能。

## 优化

- 平板和桌面的文章信息与标题占满整列，摘要和封面在下方并排，无封面时摘要使用整列。
- 视口宽度大于 800px 且小于 1024px 时收起侧栏，首页第一页显示紧凑作者入口。
- 桌面和手机的阅读进度条统一移至吸顶导航下方，图片灯箱的留白、关闭按钮和说明也重新对齐。

## 修复

- 首页首篇封面与其他文章采用同样的居中方式，长标题或长摘要时封面也能与摘要对齐。

## 使用提醒

- 平板和桌面有封面时摘要最多五行，无封面时最多四行。实际行数与末行留白随内容和屏宽变化，精准摘要未纳入本版。
- 800px 及以下沿用手机单栏布局，1024px 起显示完整侧栏。封面保持 16:10，并继续支持裁切填充和完整展示。

## 兼容性与验证

已在 Node.js 26.13.0 和 Hexo 8.1.2 下验证根路径、子路径构建及 Chromium 深浅色布局。Firefox、Safari、真实手机和线上部署尚未验证。
